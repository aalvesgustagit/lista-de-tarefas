# Lista de Tarefas em Python

Um pequeno projeto em Python para gerenciar tarefas via terminal.

## Funcionalidades

-  Adicionar novas tarefas
-  Atualizar descrição e status das tarefas
-  Deletar tarefas da lista
-  Visualizar todas as tarefas com status (concluído ou não)

##  Como usar

1. Clone este repositório ou baixe o arquivo `lista_tarefas.py`
2. No terminal, execute:

```bash
python lista_tarefas.py

- Siga o menu interativo e digite o número da opção desejada.
